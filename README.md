# PulsarDetect-Classifier-for-Pulsar-Star-Detection
A Machine Learning classification project that detects pulsar stars using astronomical signal data and predictive modeling techniques

PulsarDetect is a machine learning-based classification system designed to identify pulsar stars from astronomical observations. Using statistical features extracted from radio signals, the model distinguishes pulsar candidates from non-pulsar objects. The project demonstrates data preprocessing, exploratory analysis, model training, and evaluation for accurate pulsar detection.

## Key Features

Pulsar star candidate classification

Data preprocessing and feature analysis

Exploratory Data Analysis (EDA)

Machine learning model training and testing

Performance evaluation using classification metrics

Visualization of feature distributions and model results

Prediction of pulsar and non-pulsar candidates
